How to install in Gmail

  1. 1 Click Copy Signature above — this copies the rendered signature as rich text.
  2. 2 Open Gmail and go to Settings → See all settings → General.
  3. 3 Scroll to Signature and click Create new or click inside an existing signature box.
  4. 4 Click inside the signature editor box and paste (Ctrl+V on Windows, Cmd+V on Mac).
  5. 5 Click Save Changes at the bottom of the Settings page.

Works with Gmail. For Outlook, paste the signature in File → Options → Mail → Signatures.
